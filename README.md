# 💳 ExpenseFlow – Premium Fintech Web Application

ExpenseFlow is a sleek, modern, and fully responsive personal finance dashboard designed to simplify expense tracking and budget management. Built with a ultra-modern **Glassmorphic UI**, dynamic color accents, and full **Dual Theme (Dark/Light Mode)** support, it offers a seamless financial management experience inspired by modern fintech platforms.

---

## ✨ Features

* **🎨 Modern Glassmorphism UI:** Built with dynamic blurred backgrounds (`backdrop-filter`), glowing borders, and clean typography.
* **🌗 Dual Theme Engine:** Toggle effortlessly between Dark Mode and Light Mode via CSS custom properties.
* **📊 Visual Financial Summaries:** Key metrics display for Total Balance, Income, Expenses, and Savings.
* **🧾 Transaction History & Actions:** Itemized view for recent financial activities with instant edit/delete actions.
* **🔍 Search & Filter Bar:** Instant filtering and sorting options for quick transaction audits.
* **📱 Fully Responsive:** Adaptive layout using CSS Grid & Flexbox, complete with a collapsible mobile navigation drawer.
* **💬 Modals & Toasts:** Styled overlay forms for adding transactions and toast notifications for user actions.

---

## 🛠️ Built With

* **HTML5:** Semantic structure for optimal accessibility and performance.
* **CSS3:** Custom Variables, Modern Flexbox/Grid layouts, Glassmorphism, and Animations.
* **Google Fonts:** Powered by *Plus Jakarta Sans* for modern fintech typography.
